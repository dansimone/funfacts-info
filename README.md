# funfacts-info

Static site for the **One Fun Fact** iOS app, served via GitHub Pages at
`onefunfact.shattersoft.com`.

- `index.html` — landing / support page
- `privacy/index.html` — privacy policy

These provide the **Support URL** and **Privacy Policy URL** used in the App Store
listing. Mirrors the `kidpoints-invite` convention (named `-info` since this app
has no invites).
